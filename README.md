# freschetlab.com

Static site hosted on GitHub Pages.

- `/` placeholder home page
- `/helena/` prototype of the post-election transition site (stands in for helenafoulkes.com)
- `/Helenatransition/` earlier one-page interest prototype (Fillout form)

## /helena

- Pages are generated by `helena/_build/build.py` (shared header, nav and footer). Edit it and run `python3 helena/_build/build.py`.
- Styles: `helena/assets/site.css`. Forms: `helena/assets/forms.js`.
- Forms render as a non-submitting preview until a Fillout form ID is set in `forms.js`; then the Fillout embed replaces the preview and submissions go to Notion.
- All links are relative, so the `helena/` folder can be copied to the root of another domain unchanged.
